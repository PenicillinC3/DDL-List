DDL 清单 · 图标提案

均为自适应图标设计：背景层（色彩场）＋ 前景层（符号）。大图为桌面浏览的示意，小图行模拟桌面上 ~48px 的真实观感。每款都标注设计逻辑与适合的 UI 配对。

A · 沙漏 经典隐喻 · 稳重耐看

沙漏上半 = 流走的时间，下半缩成沙堆 = 正在逼近的 DDL；黄色沙粒是画面里唯一的暖点。抽象、克制、任何桌面背景都协调。

搭配：V1 净白 · V3 纸感

B · 双铃闹钟 提活主功能 · 直白

双铃闹钟 + 醒目指针，一句读出「到点就响」。顶部两枚铃的形状来自老式闹钟，带共鸣感；橙底在桌面上非常跳。

搭配：V2 暗夜（橙红辉光同源） · V4 活力

C · 日历截杠 语义最准 · DDL=日历上的红线

截止日 = 日历上被划掉的那一天。白历页 + 一道粗红杠，红杠颜色直接连到列表里的「已逾期」红——图标、列表、通知一套红色语言。

搭配：V1 · V3 纸感（印章呼应）

D · 倒计时圆环 现代几何 · 与列表视觉同构

进度环约走完 80%，配字母 D；青→蓝渐变和倒计时数字的荧光感同源（V2/V4 的语言）。抽象现代，适合把 app 当「仪表盘」用的用户。

搭配：V2 暗夜 · V4 分组趣弹

E · 朱印章 文化感 · 辨识度最高

朱红方印里一个「D」，印内细线框做印泥层次。图标=列表里的「已逾期」印章=界面里的批注感（V3 的体系）；米白底在满屏彩色 App 图标里很显气质。

搭配：V3 纸感 · V1（静色点缀）

F · 闪电表盘 紧迫感最强 · 年轻向

表盘被一道黄色闪电劈过：「DDL 到的一瞬间」。紫罗兰底 + 电光黄对撞，是 6 款里最外放的一枚；小尺寸下闪电轮廓依然清晰。

搭配：V4 · V2

组合气质一句话推荐
V1 + A 沙漏专业工具深蓝底沙漏与靛蓝强调色同源，桌面观感最「正经」
V2 + B 闹钟 / D 圆环暗夜仪表橙铃最直白；圆环最抽象耐看
V3 + E 印章手账文青印章 = 界面里的「已逾期」戳，产品语言完全统一
V4 + D 圆环 / F 闪电年轻炫彩几何符号配彩虹分组第一步即和谐
